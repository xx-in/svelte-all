## 四、简答题（每题8分，共24分）

1. **简述工程项目管理的定义及其核心目标。**  
   ✅ **答案：**  
   - **定义**：通过一定的组织形式，运用系统工程观点与方法，对工程项目策划、设计、施工、验收等活动进行计划、组织、指挥、协调与控制的过程。  
   - **核心目标**：保证工程质量、缩短建设工期、提高投资效益，实现质量、安全、工期、造价的综合最优。

2. **什么是总成本费用？按成本要素划分，总成本费用包括哪些内容？**  
   ✅ **答案：**  
   - **总成本费用**：项目在运营期内为生产和销售产品而发生的全部成本。  
   - **按成本要素划分**：外购材料、外购燃料、外购动力、工资及福利费、折旧费、摊销费、修理费、利息支出、其他费用。其中，经营成本 = 总成本费用 - 折旧费 - 摊销费 - 利息支出。

3. **简述风险管理的四个基本步骤。**  
   ✅ **答案：**  
   1. **风险识别**：找出可能影响项目的风险源；  
   2. **风险分析（评估）**：评估风险发生的概率和影响程度；  
   3. **风险应对**：制定规避、转移、减轻、接受等策略；  
   4. **风险监控**：跟踪风险变化，调整应对措施。

## 五、计算题（共31分）

1. **（10分）某设备原值200万元，残值率为4%，折旧年限8年。试分别用年数总和法和平均年限法计算第4年的折旧额。**  
   ✅ **答案：**  
   - **年数总和法**：  
     折旧基数 = 200×(1-4%) = 192万元  
     年数总和 = 8×(8+1)/2 = 36  
     第4年折旧率 = (8-3)/36 = 5/36 ≈ 0.1389  
     第4年折旧额 = 192×5/36 ≈ 26.67万元  
   - **平均年限法**：  
     年折旧额 = 200×(1-4%)÷8 = 24万元  
     第4年折旧额 = 24万元

2. **（12分）某项目初始投资600万元，寿命期5年，各年净收益分别为：100万元、150万元、200万元、200万元、150万元。设基准收益率为12%，试计算：  
   a) 净现值（NPV）；  
   b) 净年值（NAV）。**  
   ✅ **答案：**  
   a) NPV = -600 + 100/(1.12) + 150/(1.12²) + 200/(1.12³) + 200/(1.12⁴) + 150/(1.12⁵)  
        = -600 + 89.29 + 119.58 + 142.36 + 127.11 + 85.07  
        = -36.59万元  
   b) NAV = NPV×(A/P,12%,5) = -36.59×0.2774 ≈ -10.15万元

3. **（9分）某企业生产某产品，年固定成本为80万元，单位变动成本为30元，销售单价为60元。试求：  
   a) 盈亏平衡点产量；  
   b) 若企业希望实现年利润40万元，应达到的销售量；  
   c) 若单位变动成本上涨20%，新的盈亏平衡点产量为多少？**  
   ✅ **答案：**  
   a) Q* = 800,000 / (60-30) = 26,667件  
   b) Q目标 = (800,000 + 400,000) / (60-30) = 40,000件  
   c) 新变动成本 = 30×1.2 = 36元  
      Q*新 = 800,000 / (60-36) = 33,333件
