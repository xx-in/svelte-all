## 四、简答题（每题8分，共24分）

1. **简述工程师应具备的专业技能与职业素养（结合ABET标准）。**  
   ✅ **答案：**  
   - **专业技能**：应用数学/科学/工程知识；设计实验与分析数据；设计系统/零件/工艺；识别与解决工程问题；使用现代工具。  
   - **职业素养**：职业道德与责任；理解工程对社会/全球的影响；有效沟通；团队协作；终身学习。

2. **什么是资金时间价值？为什么在工程经济分析中必须考虑资金时间价值？**  
   ✅ **答案：**  
   - **定义**：资金在不同时间点具有不同的价值，即资金随时间推移而产生增值。  
   - **原因**：① 资金可用于投资获得收益；② 通货膨胀导致货币贬值；③ 风险因素影响资金价值；④ 不同时间点的现金流不能直接比较。

3. **简述工程项目建设程序的主要阶段及其核心任务。**  
   ✅ **答案：**  
   - **策划决策阶段**：项目建议书、可行性研究。  
   - **设计阶段**：初步设计、技术设计、施工图设计。  
   - **建设准备阶段**：征地、招标、采购、办理许可。  
   - **施工安装阶段**：土建施工、设备安装。  
   - **竣工验收阶段**：质量检验、工程移交、竣工结算。  
   - **生产运营与后评价阶段**：运营维护、项目后评价。

## 五、计算题（共31分）

1. **（10分）某企业拟投资一新项目，初始投资800万元，预计每年净收益200万元，项目寿命期6年，期末残值50万元。若基准收益率为12%，试计算该项目的净现值（NPV）并判断是否可行。**  
   ✅ **答案：**  
   NPV = -800 + 200×(P/A,12%,6) + 50×(P/F,12%,6)  
        = -800 + 200×4.1114 + 50×0.5066  
        = -800 + 822.28 + 25.33  
        = 47.61万元  
   NPV > 0，项目可行。

2. **（12分）某产品年固定成本为120万元，单位变动成本为60元，销售单价为100元，年设计生产能力为3万件。求：  
   a) 盈亏平衡点产量；  
   b) 盈亏平衡点销售收入；  
   c) 若实际销售量为2.5万件，计算安全边际率。**  
   ✅ **答案：**  
   a) Q* = 1,200,000 / (100-60) = 30,000件  
   b) R* = 30,000 × 100 = 300万元  
   c) 安全边际率 = (25,000 - 30,000) / 25,000？  
      注意：实际销量2.5万件 < 盈亏平衡点3万件，处于亏损状态。  
      安全边际率通常按（实际销量-平衡点销量）/ 实际销量计算：  
      = (25,000 - 30,000) / 25,000 = -20%（表示未达到盈亏平衡）

3. **（9分）某项目初始投资400万元，寿命期5年，各年净收益分别为：80万元、120万元、150万元、150万元、100万元。基准收益率为10%。试计算该项目的动态投资回收期（Pt′）。**  
   ✅ **答案：**  
   | 年 | 净现金流 | 折现系数 | 现值 | 累计现值 |
   |----|----------|----------|------|----------|
   | 0  | -400     | 1.0000   | -400 | -400     |
   | 1  | 80       | 0.9091   | 72.73 | -327.27 |
   | 2  | 120      | 0.8264   | 99.17 | -228.10 |
   | 3  | 150      | 0.7513   | 112.70 | -115.40 |
   | 4  | 150      | 0.6830   | 102.45 | -12.95  |
   | 5  | 100      | 0.6209   | 62.09 | 49.14   |
   Pt′ = 4 + | -12.95 | / 62.09 ≈ 4.21年
