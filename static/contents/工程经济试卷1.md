## 四、简答题（每题8分，共24分）

1. **简述科学、技术和工程的区别与联系。**  
   ✅ **答案：**  
   - **科学**：探究“是什么”“为什么”，发现规律，产出知识。  
   - **技术**：解决“怎么做”，是方法手段，产出工艺、专利。  
   - **工程**：综合应用科学与技术，在约束下实现产品/系统，产出实物或服务。  
   - **联系**：科学为基础，技术为桥梁，工程为实践。

2. **什么是工程经济学？为何在工程项目中要高度重视工程经济学？**  
   ✅ **答案：**  
   - **定义**：研究在资源有限条件下，对工程项目方案进行经济分析、评价与决策的学科。  
   - **重要性**：  
     ① 提高资源利用效率；  
     ② 降低投资风险；  
     ③ 提升项目竞争力；  
     ④ 避免“技术成功、商业失败”。

3. **简述工程项目管理中的“安全生产管理理念与管理手段”。**  
   ✅ **答案：**  
   - **理念**：以人为本。  
   - **手段**：预防为主。  
     - 消除人的不安全行为（教育、培训）；  
     - 消除物/环境的不安全状态（防护、维护）；  
     - 改善作业环境与条件。

## 五、计算题（共31分）

1. **（10分）某设备原值100万元，残值率5%，折旧年限5年。试分别用平均年限法和双倍余额递减法计算第3年的折旧额。**  
   ✅ **答案：**  
   - **平均年限法**：  
     年折旧额 = 100 × (1-5%) ÷ 5 = 19万元  
     第3年折旧额 = 19万元  
   - **双倍余额递减法**：  
     年折旧率 = 2/5 = 40%  
     第1年：100×40% = 40万元  
     第2年：(100-40)×40% = 24万元  
     第3年：(100-40-24)×40% = 14.4万元

2. **（12分）某项目初始投资500万元，每年净收益150万元，寿命期5年，无残值。基准收益率为10%。  
   a) 计算净现值（NPV）；  
   b) 计算动态投资回收期（Pt′）。**  
   ✅ **答案：**  
   a) NPV = -500 + 150 × (P/A,10%,5)  
         = -500 + 150 × 3.7908  
         = 68.62万元  
   b) 计算累计净现值：  
      第3年累计：-500 + 150×2.4869 = -126.965  
      第4年累计：-126.965 + 150×0.6830 = -24.485  
      第5年累计：-24.485 + 150×0.6209 = 68.62  
      Pt′ = 4 + | -24.485 | / 93.105 ≈ 4.26年

3. **（9分）某产品单价80元，单位变动成本35元，年固定成本180万元。  
   a) 求盈亏平衡点产量；  
   b) 若目标利润为90万元，求目标销售量；  
   c) 若单位变动成本上涨10%，新盈亏平衡点产量为多少？**  
   ✅ **答案：**  
   a) Q* = 1,800,000 / (80-35) = 40,000件  
   b) Q目标 = (1,800,000 + 900,000) / (80-35) = 60,000件  
   c) 新变动成本 = 35×1.1 = 38.5元  
      Q*新 = 1,800,000 / (80-38.5) = 43,373件
